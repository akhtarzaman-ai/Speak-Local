📖 How to build & run SpeakLocal

From zero to working audio translator in 5 minutes. Completely free.

Step 1 — Get free Gemini API key (no card!)

1
Go to aistudio.google.com/app/apikey
2
Sign in with Gmail → click "Create API Key"
3
Copy key starting with AIza... and paste into SpeakLocal
4
1,000 free requests/day forever. No card. No expiry.

Run in browser (30 seconds)

1
Download SpeakLocal.html
2
Double-click → opens in Chrome. Use Chrome for best voice support on all languages.

Install on Android phone

1
Send file to phone → open in Chrome for Android
2
3-dot menu → "Add to Home Screen" → installs as app icon

Host online for free

1
Free at github.com → new repo → upload as index.html
2
Settings → Pages → Deploy from main → live at yourusername.github.io/speaklocal

Local server

1
cd ~/Downloads npx serve . -p 3000
2
Open http://localhost:3000/SpeakLocal.html

FreeFlow audio — how to use

1
Both people share one phone (pass back and forth)
2
Rajan taps his mic → speaks in Hindi → Kumar hears it in Tamil automatically
3
Kumar taps his mic → speaks in Tamil → Rajan hears it in Hindi automatically
4

5
